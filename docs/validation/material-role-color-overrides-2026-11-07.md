# Common color override fixes — 2026-11-07

This change is separate from the device-colored screenshot addition in PR #59.

## Fixes

- Searchbar shape styles no longer override background, text and icon roles.
  Without an optional surface role, retain the existing 8% neutral background
  instead of using the page background; a supplied surface role takes precedence.
- Toggle geometry no longer overrides checked-thumb/track role colors. Explicit
  Ionic palettes retain their neutral off-state and selected-palette borders.
- Range shape styles no longer override knob/pin colors.
- Focused preferred/destructive Alert actions retain their semantic foreground/
  background pair and show an inset focus ring. Ionic's scoped focus background
  previously replaced the filled background with gray.

## Existing regression coverage

The existing normal-color screenshot suite remains 84 images. Twelve normal
baselines change because of these fixes and explicit keyboard-focus scenes for
preferred and no-cancel Alerts. Capture readiness uses hydrated content, fonts and
render frames; focused Alert scenes use real Tab navigation. CI logs individual
cases alongside the HTML report.

The image files were generated by [CI](https://github.com/webview-native-ui/ionic-theme-md3/actions/runs/42341326054),
then separated from PR #59 without changing their bytes. That run passed 229 cases
per Ionic version without flaky cases, including all 141 cases retained in this
standalone fix. The device-colored cases belong to PR #59, not this change.

Focused Alert images were also checked three times each with retries and image
updates disabled: 24 passed on each Ionic version. Final CI-generated images were
inspected directly for semantic pairs and visible focus rings.
